# Orderly — ระบบติดตามออร์เดอร์ลูกค้า

เว็บแอปหน้าเดียวสำหรับดูรายการสั่งซื้อของลูกค้า สร้างด้วย Next.js App Router และ SQLite โดยแสดงลูกค้าทุกคน แม้ยังไม่มีออร์เดอร์

## ฟีเจอร์

- แสดงชื่อลูกค้า เมือง เลขออร์เดอร์ ยอดเงิน และสถานะ
- รวมลูกค้าที่ไม่มีรายการสั่งซื้อ พร้อมข้อความ “ยังไม่มีออร์เดอร์”
- สรุปจำนวนลูกค้า จำนวนออร์เดอร์ และยอดรวม
- จัดเก็บข้อมูลใน SQLite โดยใช้ `better-sqlite3`
- สร้างฐานข้อมูลและนำเข้าข้อมูลตั้งต้นจาก `seed.sql` อัตโนมัติเมื่อเริ่มใช้งานครั้งแรก

## เทคโนโลยี

- Next.js 16 (App Router)
- React 19
- SQLite (`better-sqlite3`)

## เริ่มใช้งาน

ต้องติดตั้ง Node.js และ npm ก่อน และตรวจสอบให้มีไฟล์ `seed.sql` อยู่ในโฟลเดอร์หลักของโปรเจกต์ เช่นเดียวกับโฟลเดอร์ `my-app`

```bash
cd my-app
npm install
npm run dev
```

เปิด [http://localhost:3000](http://localhost:3000) เพื่อดูหน้าแดชบอร์ด

เมื่อเปิดแอปครั้งแรก ระบบจะสร้างไฟล์ `orders.db` ในโฟลเดอร์ `my-app` และรัน SQL ใน `seed.sql` เพื่อสร้างตารางและใส่ข้อมูลตัวอย่าง หากฐานข้อมูลมีตาราง `customers` อยู่แล้ว ระบบจะไม่รัน seed ซ้ำ

## คำสั่งที่ใช้บ่อย

```bash
npm run dev    # เริ่มเซิร์ฟเวอร์สำหรับพัฒนา
npm run lint   # ตรวจสอบโค้ดด้วย ESLint
npm run build  # สร้าง production build
npm run start  # เริ่มเซิร์ฟเวอร์จาก production build
```

## โครงสร้างสำคัญ

```text
test/
├── seed.sql              # SQL สำหรับสร้างตารางและข้อมูลตั้งต้น
└── my-app/
    ├── src/app/page.js   # หน้าแดชบอร์ดและตารางออร์เดอร์
    ├── src/app/globals.css
    ├── src/lib/orders.js # เชื่อมต่อ SQLite และ query ข้อมูล
    └── orders.db         # สร้างอัตโนมัติเมื่อเปิดแอปครั้งแรก
```

## การอัปเดตข้อมูลตั้งต้น

หากแก้ไข `seed.sql` หลังจากมี `orders.db` แล้ว การเปลี่ยนแปลงจะไม่ถูกนำเข้าอัตโนมัติ เพราะระบบไม่รัน seed ซ้ำ หากต้องการเริ่มฐานข้อมูลใหม่ ให้หยุดเซิร์ฟเวอร์และลบ `my-app/orders.db` ก่อนเปิดแอปอีกครั้ง ข้อมูลในฐานข้อมูลจะถูกสร้างใหม่จาก `seed.sql`
